# 🕌 Website Masjid IDN Boarding School

> Platform digital resmi pusat informasi, kegiatan, dan manajemen fasilitas keagamaan di lingkungan kompleks **IDN Boarding School**.

---

## 📖 Tentang Proyek

Website Masjid IDN Boarding School dirancang sebagai sarana informasi dan interaksi bagi civitas akademika pesantren (santri, asatidz, pengurus) serta masyarakat umum. Platform ini memuat berbagai jadwal kegiatan ibadah, laporan keuangan infak/sedekah, agenda kajian Islam, hingga dokumentasi kegiatan santri berbasis teknologi (*Jago IT, Pinter Ngaji*).

---

## ✨ Fitur Utama

- **🕒 Jadwal Sholat & Hitung Mundur (Countdown) Imsakiyah/Sholat Real-time:** Informasi waktu sholat harian yang akurat sesuai zona waktu setempat.
- **📅 Agenda & Kegiatan Masjid:** Informasi kegiatan harian seperti sholat berjamaah, halaqah tahfidz, kajian rutin, bimbingan dzikir, dan pesantren kilat.
- **📢 Pengumuman & Berita Pesantren:** Info seputar acara Islam, peringatan hari besar Islam (PHBI), serta kegiatan santri di masjid.
- **💰 Transparansi Keuangan (Laporan Kas Masjid):** Fitur pelaporan donasi, infak, sedekah, serta penggunaan dana operasional masjid secara transparan.
- **📱 Integrasi Galeri & Media Sosial:** Dokumentasi foto/video kegiatan keagamaan santri IDN Boarding School.

---

## 🛠️ Teknologi yang Digunakan

Proyek ini dikembangkan menggunakan teknologi web modern, antara lain:
- **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript (React.js / Next.js)
- **Backend:** Node.js / PHP (Laravel) *sesuaikan dengan stack Anda*
- **Database:** MySQL / PostgreSQL
- **Deployment:** Vercel / Netlify / VPS Hosting
